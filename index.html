Hybrid Plan v3

6-Day Evening Split (90 min/session)

Context & Goals

Context: Gym moved to ~7 PM, Monday–Saturday. Mornings are fully free for kernel study.

Goals: Fat loss, strength, muscle building, calisthenics, athletic/explosive movement.

Structure: Legs / Push / Pull / Legs / Push-Pull / Sprint+Athletic — each muscle group trained twice a week, which is the main lever for both muscle building and fat loss now that off-day cardio is gone. Sprints are consolidated into Saturday only.

Sunday — Rest

Rest and Recover. No structured session.

Time-keeping to Stay Inside 90 Minutes

  • Rest Periods: Cap rest at 2–2.5 min on the main lift, 60–90 sec on everything else.
  • Be Exact: Use a phone timer — don't eyeball it.
  • Time Constraints: If a session is running long, cut the last accessory before you cut the main lift or the explosive movement.
